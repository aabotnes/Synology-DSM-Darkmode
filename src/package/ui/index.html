One-time setup

DSM only lets the system itself change its own look, so dark mode needs one task that runs as root. It also reapplies dark mode after DSM updates.

  1. Open Control Panel > Task Scheduler.
  2. Click Create > Triggered Task > User-defined script.
  3. Name it Dark Mode, set User to root and Event to Boot-up.
  4. On the Task Settings tab, paste this into Run command:
    /var/packages/DarkMode/target/bin/darkmode apply
  5. Click OK, select the task and click Run once.
  6. Reload DSM in your browser.

Turning it off

Stop the Dark Mode package in Package Center and reload DSM. Start it again to switch dark mode back on.

Removing it completely

Before uninstalling, change the task's Run command to the line below and run it once, then delete the task and uninstall the package.

/var/packages/DarkMode/target/bin/darkmode revert
